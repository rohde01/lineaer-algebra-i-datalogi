# Lineær algebra i datalogi

Københavns Universitet · BSc i datalogi-økonomi · Forår 2023, blok 4 · 7,5 ECTS  
Kursuskode NMAB15002U · [Kursusbeskrivelse](https://kurser.ku.dk/course/nmab15002u)

Lineær algebra med datalogisk vinkel: vektorrum, lineære afbildninger, egenværdier og matrixfaktoriseringer som QR.
